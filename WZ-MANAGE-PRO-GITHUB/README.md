# WZ MANAGE PRO WEBSITE v1

Website shell yang bisa dijalankan sebagai aplikasi Next.js.

## Jalankan
1. Install Node.js LTS.
2. `npm install`
3. `npm run dev`
4. Buka `http://localhost:3000`

## Status
UI/navigation sudah tersedia. Data backend, authentication nyata, database, payment gateway, dan deployment internet masih harus dihubungkan sebelum digunakan untuk operasional nyata.
